# Module Introduction à la sécurité - 3A FISA Cyber 2026-2027
## Quelques rappels 
* Pour chaque exercice réalisé, un write-up sera **obligatoire**
* Pour rappel, un write-up est un document rédigé expliquant votre démarche de manière **détaillée**
* Votre travail devra être réalisé pendant les heures de cours et vous devez contacter votre
intervenant avant chaque validation de challenge
* Vous serez interrogé aléatoirement sur une des séances du module pour soutenir à l'oral et présenter
un des write-up que vous avez réalisé s'en suivra une session de questions
* **Attention, tout plagiat, triche de quelque manière que ce soit sera sanctionné
systématiquement par un constat de fraude. Vous pouvez être évalué ou questionné à tout
moment sur votre travail. L'usage de l'IA est formellement interdit**
* **Tout abus sur le Github sera sanctionné**

## Fonctionnement du dépôt 
* Pour chacun d'entre-vous il existe un sous-dossier à votre nom
* Vous devez placer à l'intérieur chaque write-up que vous écrirez au fur et à mesure que vous avancez dans les challenges
* Attention, vous devez l'uploader au sein d'une archive nommée de la même manière et protégée par le mot de passe que vous m'avez communiqué. Il devra être le même sur chaque archive.
* Chaque document devra être nommé de la manière suivante : NOM_WU_NOM_DU_CHALLENGE.FORMAT
* Format au choix : MD ou PDF
* Votre template devra également être présent dans votre sous-dossier sous la nomenclature suivante : NOM_TEMP_WU.FORMAT
